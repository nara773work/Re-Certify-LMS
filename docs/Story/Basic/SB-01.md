# Feature

Feature Name:質問掲示板
Purpose:質問をまとめて掲示し、閲覧・回答ができるようにする
詳細設計時間：1~2時間目標
実装時間：2時間目標

# Process

1. 質問掲示板を表示する
2. 未解決・解決、資格別に検索
3. スレッド詳細画面を表示する
4. スレッドを作成する
5. スレッドを編集する
6. スレッドに回答を投稿する
7. スレッドを解決済みに変更する
8. スレッドを未解決に戻す
9. 管理者がスレッド・回答を管理する
10. 入力値をバリデーションする
11. スレッド作成成功 → スレッド詳細画面へ
12. スレッド作成失敗 → エラーメッセージ表示

# Database

Table:question_threads
- id
- user_id(nullable,On delete Set Null)
- certification_id(cascade On delete)
- is_resolved
- timestamps
- title
- body (2000)

Table:answres
- id
- user_id(On delete Set Null)
- thread_id(cascade On Delete)
- timestamps
- body (2000)

# Notes

- 「質問」「回答」をDBに保存するため新規テーブルを2つ作成する。
- User to question thread = 1:N
- User to answer = 1:N
- ユーザーが退会しても質問を閲覧できるように質問や回答自体はSet nullとする
- 質問スレッドが削除された場合、回答が残っても意味がないのでcascade on deleteとする
- 投稿時に一覧画面に戻ると操作性が悪いので詳細画面にリダイレクトする
